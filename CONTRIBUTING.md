# 🤝 Contributing to MSM Classes

Thank you for your interest in contributing to **Maa Saraswati Mentors Classes (MSM Classes)**!

We're building India's most trusted AI-powered education platform — and we'd love your help.

---

## 🧭 Before You Start

1. Read our [Code of Conduct](./CODE_OF_CONDUCT.md)
2. Browse [open issues](https://github.com/msmclass) and look for `good first issue` or `help wanted` labels
3. For large changes, **open an issue first** to discuss your approach

---

## 🛠️ Development Setup

```bash
# Clone the repository
git clone https://github.com/msmclass/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📋 Contribution Guidelines

### Branch Naming
| Type | Pattern | Example |
|---|---|---|
| Feature | `feature/short-description` | `feature/ai-quiz-engine` |
| Bug Fix | `fix/issue-description` | `fix/login-redirect-loop` |
| Docs | `docs/what-you-changed` | `docs/update-api-readme` |
| Refactor | `refactor/what-changed` | `refactor/video-service` |

### Commit Messages (Conventional Commits)
```
feat: add adaptive quiz scoring engine
fix: resolve WebRTC ICE candidate failure
docs: update Samvaad API documentation
refactor: simplify authentication flow
chore: upgrade dependencies to latest
```

### Pull Request Checklist
- [ ] Code follows project style guidelines
- [ ] Tests added / updated (if applicable)
- [ ] Documentation updated
- [ ] No breaking changes (or clearly documented)
- [ ] PR has a descriptive title and clear description
