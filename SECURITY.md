## 🚨 Reporting a Vulnerability

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, email us directly at:

📧 **[info@msmclass.in](mailto:info@msmclass.in)**

Include the following in your report:
- Type of vulnerability (e.g., XSS, SQL injection, auth bypass)
- Affected component and version
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

### Our Commitment
- We will acknowledge your report within **48 hours**
- We will provide a detailed response within **7 days**
- We will notify you when the vulnerability is patched
- We appreciate responsible disclosure and will credit researchers (if desired)
