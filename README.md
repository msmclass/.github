## 🏛️ Organization Profile

The file at [`profile/README.md`](./profile/README.md) is automatically displayed as the **public face** of the MSM Classes GitHub organization at [github.com/msmclass](https://github.com/msmclass).

It includes:
- 🎨 Branded banner and animated headline
- 🎯 Overview of all offerings (academics, coding, music, dance)
- 🤖 AI learning platform features
- 📹 Samvaad video platform highlight
- 📊 Impact stats (5000+ students, 200+ tutors)
- 🛠️ Tech stack badges
- 📁 Repository index
- 📞 Contact & social links

## 📝 Default Templates

These files apply as defaults to **all repositories** under the `msmclass` organization unless a repo overrides them with its own `.github/` folder.

### Issue Templates

| Template | File | Purpose |
|---|---|---|
| 🐛 Bug Report | [`ISSUE_TEMPLATE/bug_report.md`](./ISSUE_TEMPLATE/bug_report.md) | Structured bug reports with environment info |
| 💡 Feature Request | [`ISSUE_TEMPLATE/feature_request.md`](./ISSUE_TEMPLATE/feature_request.md) | Proposal template with area checkboxes |

### Pull Request Template

[`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) — Pre-filled checklist for every PR:
- Type of change (bug fix / feature / docs / refactor)
- Test coverage confirmation
- Before/after screenshot slots
- Reviewer notes section

## 🖼️ Updating Images

Images are stored in [`images/`](./images/). To replace with official branding:

| File | Recommended Size | Notes |
|---|---|---|
| `banner.png` | ~900×160px | Replace with official MSM logo/banner |
| `stats.png` | ~900×80px | Replace with live stats widget or updated image |

After uploading new images, **no README edits are needed** — paths are already configured.

## 🛠️ How to Modify This Repo

```bash
# Clone
git clone https://github.com/msmclass/.github.git
cd .github

# Make changes to any file
# e.g., update profile/README.md, add a new issue template, etc.

# Commit & push
git add .
git commit -m "docs: update org profile / templates"
git push origin main
```

> ℹ️ Changes to `profile/README.md` take effect immediately on the GitHub org page after push.
